# 実働時間は割当に焼き込んだ休憩から導出する

各 **割当 (Assignment)** は自身の `rest_minutes` を保持する。これは割当の生成時・手動編集時に **シフトパターン (Shift Pattern)** からスナップショットした値であり、給与計算のたびにパターンを参照するのではない。こうすることで、後からパターンを編集・削除しても過去の給与が動かない。**実働時間 (Worked Hours)** = `max(0, 総スパン − rest_minutes/60)` は導出値であり、DB カラムとしては持たない。移行前の既存割当は `rest_minutes = 0` のまま据え置く（遡及変更しない）。

**深夜割増 (Overnight Premium)** は、実働時間ではなく **総スパン** の深夜帯に対して計算する点が意図的な逸脱である。休憩は「分（長さ）」のみで時刻位置を持たないため、休憩が 22:00–05:00 帯に重なるか判定できない。そこで当面は「休憩は昼間に取る」と仮定して割増を減らさない。これは暫定であり、先方確認後に按分控除へ変更する可能性がある。

## Considered Options

- **休憩をパターンから都度参照**（却下）: パターン編集・削除で過去の確定給与がブレる。
- **実働時間を数値カラムで保存**（却下）: 導出値の二重管理で陳腐化する。
- **深夜割増を実働に按分控除**（保留）: 休憩の時刻位置を持たない現状では根拠が薄い。位置を持たせる設計に格上げしてから再検討。
