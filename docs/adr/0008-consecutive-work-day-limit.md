# 連勤を全従業員一律で最大4連勤に制限する

労務上の理由で、全従業員一律に**5連勤以上を禁止（最大4連勤）**したい。スケジューラで、各従業員・生成月内の**連続5日窓すべて**について「窓内の勤務日数 ≤ 4」をハード制約にする。`x[e,d,p]` は「1日1パターン以下」制約済みなので、日ごとの勤務は `Σ_p x[e,d,p]`（0/1）で表せる。

**月をまたぐ連続は対象外**（前月末→今月頭の連続は数えない）。前月シフトを参照せず生成月内で完結させ、実装をシンプルかつ確実にするため。

## Considered Options

- **月をまたいでカウント**（却下）: 前月確定シフトの参照が必要で複雑。境界の数日のためにコストが見合わない。運用上は月頭の数日が最大4+αになり得るが許容とする。
- **ソフト制約（ペナルティ）**（却下）: 「5連勤以上はダメ」は明確な上限のためハードが適切。第3段フォールバックがカバレッジ不足を許容するので、この制約が原因で解なしにはなりにくい（休ませればよい）。

## Consequences

- 毎日 必要人数を満たすには、従来より多くの人員が要る場合がある（各人が定期的に休むため）。従業員2人で毎日 朝1+夜1 を回すような密なケースは連勤制限で満たせなくなる（人員追加が必要）。
- 定数 `MAX_CONSECUTIVE_DAYS = 4`（`scheduler.py`）。
