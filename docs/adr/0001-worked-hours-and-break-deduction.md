# 実働時間は現在のパターンの休憩から算出する（スナップショットはフォールバック）

給与計算は各 **割当 (Assignment)** について、現在の **シフトパターン (Shift Pattern)**(`shift_type` = code）の `rest_minutes` を計算時に都度参照し、**実働時間 (Worked Hours)** = `max(0, 総スパン − 休憩/60)` を算出する。パターンの休憩を変更すれば、シフトを再生成しなくても**人件費を再計算するだけで反映**される（「人件費に関わる変更は常に最新で計算する」という要件）。

割当にも `rest_minutes` をスナップショットとして保持する。用途は (1) 対応するパターンが削除された場合のフォールバック、(2) シフト表セルでの実働表示。既存（移行前）割当のスナップショットは 0 のまま据え置くが、パターンが存在する限り給与計算には影響しない（現在のパターン値が優先される）。

**深夜割増 (Overnight Premium)** は実働時間ではなく総スパンの深夜帯に対して計算する。休憩は「分（長さ）」のみで時刻位置を持たず、22:00–05:00 帯に重なるか判定できないため、当面は「休憩は昼間に取る」と仮定する。暫定であり、先方確認後に按分控除へ変更する可能性がある。

## Considered Options

- **割当スナップショットを給与の唯一の真実源にする**（却下）: パターンの休憩を変えても、シフトを再生成するまで人件費に反映されず運用と噛み合わない。
- **実働時間を数値カラムで保存**（却下）: 導出値の二重管理で陳腐化する。
- **深夜割増を実働に按分控除**（保留）: 休憩の時刻位置を持たない現状では根拠が薄い。位置を持たせる設計に格上げしてから再検討。
