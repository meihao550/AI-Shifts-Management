# AI-Shifts-Management 要件定義書

> ※プロジェクト名は仮決定

---

## 1. 開発の経緯・目的

### 1.1 前回プロダクトで残った課題

- 従来システムのリファクタリングに留まり、**労力削減**という目的を達成できなかった
- **AIを使って楽をしたい**という目的に沿えなかった
- 機械系(機械学習系)は学習コストが高いため、**学習コストの少ないもの**を作りたい

### 1.2 課題を解決することで得られる効果

- スケジューリング問題の解法とAIを活用し、**30分以内**でシフト作成を行えるようにする
- 通常業務に集中させることで**利益増加**を見込める
- 学習コストが少なく操作でき、**ミスによるシステム破壊を防げる**
- 担当者が変更しても、引き続き同じシステムを使用できる

## 3. 開発スコープ

### F-1: AIシフト機能

- 生成AIとCP-SATによる制約プログラミングによってシフトを作成する
- **生成AI**：その月特有の事情を自然言語で入力すると、それを解釈して制約として判断する。自然言語を処理し、JSON形式に変換して制約とする
- **CP-SAT**：従業員ごとの制約をすべて組み合わせ、実際のスケジューリング問題を解いてシフトを出力する

### F-2: 人件費自動計算機能

- 全体の1ヶ月の人件費と、その日1日の人件費を計算する
- 労働時間から社会保険・雇用保険を適用するかどうかを判断する

## 4. 画面・機能要件

### 4.1 ログイン画面

シフト管理者・一般社員でできる機能を制限し、また第三者が誤ってサイトに来た際に中を見られないようにするため。

- **Google Workspace認証（OAuth認証）** を想定
- ログイン後はダッシュボードへ遷移する

### 4.2 ダッシュボード

ログイン後に最初に表示する画面。今月のシフトが表示され、各機能への入り口となる。

- 1ヶ月の人件費を表示する
- 従業員個人の総勤務時間を表示する
- シフト管理者・一般社員ともに、この画面ではシフトを編集できない（**表示のみ**）
- **26日**になったら通知する
- 「シフトを編集する」ボタンを表示し、押下でシフト表画面へ遷移する

### 4.3 従業員管理画面

従業員の情報を詳細に入力できる。

| 入力項目                         | 備考                                                             |
| -------------------------------- | ---------------------------------------------------------------- |
| Google Workspaceのメールアドレス | 登録されれば従業員も本システムを使用可能。未登録でも表示はされる |
| 名前                             |                                                                  |
| 年齢                             |                                                                  |
| 交通費                           |                                                                  |
| メインで入るシフト               |                                                                  |
| 週に何回入るか                   |                                                                  |

### 4.4 ルール設定画面

（詳細は今後詰める）

### 4.5 シフト表画面（メイン）

#### 入力フェーズ

1. シフト管理者が各従業員の **休日希望（絶対的勤務不可能日）** と **入りたいシフト** を入力する
2. 「シフト作成」ボタンを押す
3. 生成AIが自然言語を整理し、CP-SATが各画面で入力されたハード制約・ソフト制約を満たす決定変数を出力してシフトを生成する
4. **生成の進捗を表示する**

#### 現時点でわかるハード制約：必要人数

必要人数は曜日ごとに決める。

| 区分             | 朝  | 夜  | 深夜 |
| ---------------- | --- | --- | ---- |
| 金・土・日＋祝日 | 3人 | 3人 | 1人  |
| 平日             | 2人 | 2人 | 1人  |

#### シフトパターン

**基本**

| 区分 | 時間帯       |
| ---- | ------------ |
| 朝   | 9:00 - 17:00 |
| 夜   | 17:00 - 1:00 |
| 深夜 | 1:00 - 9:00  |

**例外**（2つ以上仕事を掛け持ちする人）

9〜15 / 9〜16 / 10〜17 / 10〜18 / 12〜20 / 15〜23 / 18〜20 / 18〜1 / 20〜1

#### 生成後（結果表示・手動編集）

シフト表が作成できた後、生成結果の表示と手動編集ができる中心画面に遷移する。

- 曜日の自動入力、土日祝の色分けを行う（＝カレンダーのような表示）
- 手動編集：該当するシフトのセルを押すと、プルダウンリストから選択できる
- **PDF** と **Excelファイル** に出力できる
- PDFボタン／Excelボタンを押すと印刷プレビュー画面へ遷移する

### 4.6 人件費計算画面

シフト表（この画面からの変更は不可）と人件費の計算結果を表示する。

- 1日の人件費の結果を表示
- 一人ひとりの人件費の結果を表示
- 合計を表示
- **すべて表形式**

#### 保険の基準値

| 区分            | 条件                     |
| --------------- | ------------------------ |
| 社会保障        | 月120時間以上            |
| 雇用保険 加入   | 月80時間以上 119時間まで |
| 雇用保険 未加入 | 月79時間以内             |

#### 割増賃金の扱い

- 割増賃金（深夜料金など）は**人件費に含める**
- 人件費とは「その人に関わる全ての金額」であり、本来は有給・交通費も含まれる

- PDFボタン・Excelボタンを押した後、細かく編集できるようにする

## 6. 技術スタック

チーム開発を想定しており、チーム開発に便利なツールは積極的に採用する。

| 層                     | 技術                                              | 選定理由                   |
| ---------------------- | ------------------------------------------------- | -------------------------- |
| フロント               | Vue 3                                             | リアクティブな表に適合     |
| 状態管理               | Pinia                                             | Vueの公式ライブラリ        |
| ルーティング           | Vue Router                                        | SPAで画面遷移              |
| UI                     | Naive UI                                          | 表・カレンダーを効率構築   |
| 言語（フロントエンド） | TypeScript                                        | 型安全                     |
| API                    | FastAPI                                           | OpenAPI自動生成            |
| 検証                   | Pydantic v2                                       | 入出力スキーマ検証         |
| 最適化                 | OR-Tools CP-SAT                                   | シフトスケジューリング     |
| ORM                    | SQLAlchemy 2.0 + Alembic                          | マイグレーション管理       |
| DB                     | Supabase (PostgreSQL)                             | 開発に便利                 |
| 非同期処理             | FastAPI BackgroundTasks                           | 最適化計算をAPIから分離    |
| 認証                   | Google Workspace (OAuth) / Magic Link or Supabase | パスワード管理の負荷を低減 |
| 祝日                   | JPholiday (Python)                                | 土日祝日判定               |
| デプロイ               | AWS + Terraform                                   | 楽だから                   |
